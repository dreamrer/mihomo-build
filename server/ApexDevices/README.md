# 登录设备识别(ApexDevices)· Xboard 插件

让 Apex 客户端「我的 → 登录设备管理」显示每个会话是哪台设备(型号、系统、登录 IP),并认出本机。

## 为什么需要

Xboard 登录时只建一条令牌,令牌里没有设备信息,客户端只能显示"会话 #编号"。
v2board 面板本来就记录 UA 和 IP,**v2board 不需要这个插件**。

## 安装

1. 把整个 `ApexDevices` 目录放到面板的 `plugins/` 下(目录名必须是 `ApexDevices`)。
2. 后台 → 插件管理 → 找到「登录设备识别」→ 安装 → 启用。
3. docker/Octane 部署执行一次 `docker compose restart`(或面板里"重启服务")让新插件代码加载。

## 生效范围

- 启用后**新登录**的会话:立即带设备信息。
- 启用前已经登录的会话:它下一次访问面板(打开 App、刷新订阅信息)时自动补上。
- 要显示机型,客户端要 4.9.6 及以上;旧客户端和网页端登录的会话也会记下它们的 UA,只是显示成"系统 · 浏览器"。

## 写了什么

令牌表 `personal_access_tokens.name` 从随机串改成 `apexdev1|<IP>|<User-Agent>`。
这个字段 Xboard 自己不读(只是建令牌时随手填的名字),不影响登录、鉴权、踢下线。
停用插件后新令牌恢复成随机串,已写入的不回滚(无害)。

## 隐私

IP 只给用户本人在自己的设备列表里看,客户端展示时只露前两段。后台配置里可以关掉「记录登录 IP」。
